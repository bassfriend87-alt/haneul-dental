# /about 원장 소개 페이지 리디자인 스펙

## 목적
기존 about 페이지는 사진 1장 + 텍스트 블록 나열 구조로 정보 위계가 없음.
신뢰 신호(전문의 자격)를 우선 노출하고, 브랜드 차별점을 카드로 구조화하며,
이력을 타임라인으로 재구성한다.

## 브랜드 컬러
- 오렌지: #F5890A (포인트, 강조선, 아이콘)
- 차콜: #585858 (보조 배경, 텍스트)

## 섹션 구조 (위→아래)

### 1. 히어로 (2단 분할)
- 좌: 원장 프로필 사진 (기존 `doctor-profile-stand-white.jpg` 또는 진료 사진으로 교체 검토)
- 우:
  - 전문의 배지 2개 (치과보철과 전문의 / 통합치의학과 전문의) — 이름보다 위에 배치
  - 원장명 + 클리닉명 + "상암동 단독 개원"
  - pull-quote: **"환자분이 이해하실 때까지, 설명을 아끼지 않습니다"** (좌측 오렌지 보더 라인 강조)
    - ※ "잘 만든 보철은, 환자가 잊고 삽니다"는 홈페이지 h1 및 /treatment/prosthetics 전용 문구로 유지.
      about 페이지는 제품 슬로건이 아닌 원장 개인의 목소리를 담아 구분함.

### 2. 차별점 3카드 ("왜 한 사람이 끝까지 책임지는가")
동일한 3분할 카드, 홈 화면과 동일 톤 유지 (사이트 전체 메시지 일관성 목적)
1. 정직한 진단 — 있는 그대로 설명, 과잉 치료 지양
2. 충분한 설명 — 환자가 이해하고 스스로 선택
3. 평생 책임 관리 — 진단부터 제작·장착·관리까지 한 사람이 담당

주의: 의료법 제56조 금지 표현(최고/최다/유일/100%) 사용 금지, 객관적 진술 유지.

아이콘: `@tabler/icons-react` 패키지 사용 (outline 스타일)
- 정직한 진단: `IconStethoscope`
- 충분한 설명: `IconMessageCircle`
- 평생 책임 관리: `IconCrown`
- 색상: #F5890A, 크기 24px
- 설치: `npm install @tabler/icons-react`

### 3. 진료 철학 (pull-quote + 배경 사진)
- 기존 철학 문단을 큰 인용구 형태로
- 배경에 진료 사진 은은하게 (있다면 상담/진료 장면 사진 사용)

### 4. 학력 및 경력 — 세로 타임라인
- 기존 불릿 리스트 → 좌측 세로선 + 오렌지 점(#F5890A) 타임라인으로 변경
- 시간순 정렬

### 5. 학회 활동 — 배지/칩 형태
- 기존 리스트 → 가로 나열 칩 형태 (background: surface-1 톤)

### 6. 예약 CTA
- 기존 유지

## 기술 참고
- Next.js + Tailwind CSS
- 반응형: 모바일에서는 히어로 2단 분할 → 1단으로 스택
- next/image로 사진 자동 최적화 (수동 압축 불필요)
